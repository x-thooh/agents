# 踩坑记忆

一条一个坑，三段缺一不可：现象 / 根因 / 落成的断言。**没有第三条的条目不算记忆**——
那只是抱怨。落成的断言要么指向 `scripts/scopes/` 里的一个 code，要么在 `AGENTS.md`
的「人判项」里写明强度来源。

## L-1 示例数据被当成真交付

- 现象：`make check` 全绿，但交付时门记录里全是 `example: true` 的占位。
- 根因：校验只看字段齐不齐，没区分占位与真实证据。
- 断言：`EXAMPLE001`——`--strict` 下示例数据判 ERROR。

## L-2 跳阶没人拦

- 现象：前一阶段 `reject`，后一阶段照样填 `pass`。
- 根因：门记录之间没有顺序约束，每个文件单独看都合法。
- 断言：`GATE004`——前序未通过时后续 `pass`/`conditional` 判 ERROR。
